## Featured projects

### [Minishell](https://github.com/tommysoeder/minishell)

A collaborative Unix shell written in C with a teammate, implementing command execution, pipelines, redirections, environment expansion, built-ins, and interactive signal handling. My main contributions covered signal management, environment-variable expansion, part of the parser, and integration and debugging.

**Demonstrates:** processes, `fork`/`execve`, pipes, file descriptors, signals, parsing, memory management, and collaborative development.

### [Philosophers](https://github.com/tommysoeder/Philosophers)

A dining philosophers simulation built with POSIX threads and mutexes. The implementation coordinates shared forks, tracks meal timing, monitors philosopher state, handles the single-philosopher case, and supports an optional meal quota.

**Demonstrates:** concurrency, synchronization, mutex-protected shared state, timing, thread lifecycle management, and resource cleanup.

### [push_swap](https://github.com/tommysoeder/push_swap)

A constrained sorting project using two doubly linked stacks and a fixed operation set. It applies specialized strategies to small inputs and binary radix sorting with index compression to larger inputs.

**Demonstrates:** linked data structures, strict input validation, algorithmic tradeoffs, bitwise processing, and operation-based sorting.

### [so_long](https://github.com/tommysoeder/so_long)

A small 2D game in C using MiniLibX. It parses and validates tile maps, checks objective reachability with flood fill, handles keyboard and window events, renders XPM textures, and releases graphical and map resources on exit.

**Demonstrates:** event-driven programming, grid algorithms, file parsing, graphics integration, validation, and resource management.

### [Minitalk](https://github.com/tommysoeder/minitalk)

A client-server communication project that encodes message bytes into `SIGUSR1` and `SIGUSR2`. The server reconstructs each byte with bitwise operations and writes the received message to standard output.

**Demonstrates:** Unix signals, process identifiers, `kill`, `sigaction`, asynchronous communication, and bit-level encoding.

### [KamikApp](https://github.com/tommysoeder/KamikApp)

A personal full-stack prototype for improving communication and coordination in a sports club. It combines a responsive vanilla JavaScript frontend with a Node.js backend, role-aware workflows, JSON persistence, authentication, calendars, call-ups, attendance, documents, and messaging.

KamikApp is a developed prototype for local evaluation. It is **not deployed and has not been used in production**.

**Demonstrates:** product thinking, frontend and backend integration, HTTP APIs, authentication, role-based behavior, persistence, and iterative testing.
